**NetGuard** — современное нативное приложение для Windows с дизайном в стиле **Google Material You (Material 3)** для комплексного аудита сетевой безопасности, правильности конфигурации IP-стека и обнаружения уязвимых служб.

> ⚡ **НЕ веб-приложение!** Работает как легковесный автономный исполняемый `.exe` файл (WPF), не требует браузера, Electron, Node.js или Python. Потребляет менее 40 МБ оперативной памяти и запускается за доли секунды.

## 🔍 Возможности аудита и проверок безопасности

### 1. 📊 Комплексный скоринг безопасности (0 - 100%)
- Автоматический расчет индекса защищенности локальной сети и системы.
- Категоризация угроз: **Безопасно**, **Требуется внимание**, **Критическая угроза**.

### 2. 🛡️ Аудит политик безопасности и уязвимых служб Windows
- **Брандмауэр Windows (Windows Firewall)**: проверка активности всех 3 профилей (Доменный, Частный, Общедоступный). Обнаружение отключенных профилей, оставляющих ПК беззащитным.
- **Устаревший протокол SMBv1**: проверка наличия уязвимости EternalBlue / WannaCry. Рекомендация и команда немедленного отключения.
- **Удаленный рабочий стол (RDP / порт 3389)**: детекция активности RDP и обязательности аутентификации на уровне сети (NLA).
- **Широковещательный протокол LLMNR**: проверка риска перехвата и отравления NTLM-хэшей в локальной сети (Responder-атаки).
- **Служба удаленного реестра (RemoteRegistry)**: проверка статуса службы удаленного редактирования системного реестра.
- **Целостность файла hosts**: детекция несанкционированных перенаправлений доменов в `drivers\etc\hosts`.

### 3. 🔌 Анализ открытых прослушиваемых локальных портов (TCP)
- Глубокое сканирование через `IPGlobalProperties`.
- Определение доступности службы: открыта ли она на `0.0.0.0` (видна всем в локальной сети и Wi-Fi) или заблокирована на `127.0.0.1` (только localhost).
- Автоматическое распознавание протоколов: FTP, SSH, Telnet, HTTP, SMB, MS-RPC, RDP, WinRM, ADB, Ollama AI и др. с оценкой уровня риска.

### 4. 🌐 Анализ сетевых адаптеров, шлюза и DNS
- Подробные параметры интерфейсов (IPv4, маска, MAC, шлюз, скорость линка).
- Проверка доступности основного шлюза (роутера) с измерением пинга и задержки в миллисекундах.
- Тест DNS-резолвинга (google.com) с оценкой скорости и проверка на использование защищенных резолверов (Cloudflare 1.1.1.1, Google 8.8.8.8, Quad9 9.9.9.9) вместо открытого DNS провайдера.
- Определение публичного внешнего IP и верификация защищенного HTTPS-канала.

### 5. 💡 Центр рекомендаций и однострочные PowerShell-фиксы
- Для каждой обнаруженной проблемы формируется готовая проверенная команда PowerShell для исправления.
- Кнопка **«Скопировать команду»** в 1 клик для быстрой вставки в терминал администратора.

### 6. 📄 Экспорт отчетов
- Экспорт полного отчета аудита в форматы:
  - **Текстовый отчет (`.txt`)**
  - **Структурированный JSON (`.json`)** для автоматизации и интеграции.

## 🚀 Запуск и сборка

### Запуск готового приложения
Исполняемый файл уже скомпилирован и находится в папке:
```
bin\Release\NetGuard.exe
```
Просто запустите его двойным кликом — приложение готово к работе на любой Windows 10 или Windows 11!

### Сборка из исходников
Для сборки используется стандартный компилятор MSBuild, входящий в состав Windows:
1. Запустите скрипт `build.bat` двойным кликом.
2. Либо выполните в PowerShell:
```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe" NetGuard.csproj /p:Configuration=Release
```

```
├── NetGuard.csproj             # Файл проекта MSBuild
└── README.md                   # Документация проекта
```
